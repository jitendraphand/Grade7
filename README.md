# Grade7 Physics Foundation Quiz

Self-contained HTML quiz with **50 MCQs** on **Kinematics, Heat, Measurement & Light** for Grade 7, based on JEE & NEET foundation preparation.

## Features
- 50 carefully selected multiple-choice questions
- **60 seconds** timer per question (auto-advances if time expires)
- Full navigation: jump to any question via palette
- Progress tracking, scoring, and answer review
- Responsive, self-contained (single HTML file)
- Topics aligned with Class 7 foundation curriculum

## Live Quiz
**GitHub Pages URL:** https://jitendraphand.github.io/Grade7/

> **Note:** If the page is not yet live, enable GitHub Pages:
> 1. Go to repo **Settings** → **Pages**
> 2. Under **Build and deployment**, select **Deploy from a branch**
> 3. Choose **main** branch and **/ (root)** folder
> 4. Save. The site will be available at the URL above within a minute.

## Local Use
Open `index.html` directly in any browser. No server required.

Enjoy practicing!
